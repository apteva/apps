# Processes 0.24.3

The project map is simpler.

- It opens on SOPs with an active assignment (an active assignment on an
  active SOP), plus any SOP with a live run. A dropdown switches to "All SOPs";
  the status filter shows counts per status.
- Each SOP is a compact card: its header plus a strip with one segment per
  step, coloured by the live run's step state. "Show steps" expands a SOP into
  its full step graph and zooms to it; SOPs with a live run start expanded.
  "Show all steps / Hide all steps" toggles every visible SOP.

UI only.

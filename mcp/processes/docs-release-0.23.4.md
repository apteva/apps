# Processes 0.23.4

The process list uses desktop space better. Each process takes two lines: the
name with its category and tags as small pills, then a one-line description
(full text on hover). Agents, assignments, status, version and updated take only
the width they need; agent names truncate with a tooltip and dates are short
("15:48" today, "24 Nov" otherwise). Agents and version hide on small screens.
UI only.

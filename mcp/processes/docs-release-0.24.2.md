# Processes 0.24.2

Schedules in the Assignments "Starts" column match event triggers: a clock
icon, a plain-language title ("Every Monday at 09:00", "Every weekday at
18:00", "Hourly at :15, 09:15–23:15", "Every 2 hours"), and the next run with
its timezone underneath. Uncommon cron expressions show as written; the raw
cron stays in the tooltip. UI only.

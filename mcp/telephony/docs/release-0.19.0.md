# Telephony 0.19.0

- Provision browser destinations and independent phone-resource grants through
  app-only tools scoped by operator-approved calling installations, projects,
  principal authorities, resources and ordinary call actions.
- Retry provisioning safely with stable IDs, opaque revisions and atomic
  resource changes, idempotency receipts and audit records.
- Apply grants to browser controls, event visibility, media attachment and
  reconnect checks. Explicitly disabled legacy users stay denied.
- Preserve legacy access policy, destinations, call ownership and history across
  the additive migration. Operator edits advance destination revisions.

This initial extension supports browser users and ordinary call actions.
Supervision delegation and business account creation require separate work.

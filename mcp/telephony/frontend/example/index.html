A few lines. A complete softphone.

The page supplies the layout. The installed Telephony app supplies the call behavior.

const loaded = await sdk.apps.load("telephony", {
  projectId, installId
});
const phone = loaded.client.createSoftphone();

phone.subscribe(renderCallState);
await phone.dial({ to: "+15550100100" });
phone.setMuted(true);
await phone.hangup();

# Changelog

## 0.2.0

- Add EPUB 3 export with cover, images, navigation, semantics, and accessibility metadata.
- Add official EPUBCheck integration with a built-in structural fallback and downloadable report.
- Add trim-aware print PDF export with embedded Unicode fonts and mirrored margins.
- Add ebook cover, print-cover, and interior-image asset management.
- Add contributors, series, identifiers, categories, keywords, audience, rights, territories, pricing, AI disclosure, accessibility, and print settings.
- Add Kindle, Apple Books, Kobo, Google Play Books, print, and universal publication packages.
- Add publication readiness checklists and expose publication controls in the Books panel.
- Include notes when `include_notes` is requested.
